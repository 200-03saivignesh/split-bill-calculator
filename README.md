# 💸 Split Bill Calculator

A sleek, high-tech split bill calculator built with vanilla HTML, CSS, and JavaScript. Perfect for tracking shared expenses among friends, roommates, or group outings.

## 📋 Features

- **Add Participants**: Easily add people with custom names and profile photos
- **Add Expenses**: Log expenses with descriptions, amounts, and who paid
- **Real-time Summary**: 
  - Total expenses tracked
  - Balance calculations
  - Average expense per person
  - Highest and lowest spenders
  - Remaining balance verification
- **Responsive Design**: Modern, sleek dark-themed UI that works on all devices
- **Photo Support**: Upload participant photos with profile customization
- **Download Option**: Export your bill summary

## 🎨 Design Highlights

- **Modern UI**: Dark theme with gradient backgrounds and smooth animations
- **Interactive Elements**: Real-time calculations and updates
- **Custom Avatars**: Auto-generated colored initials for participants without photos
- **Professional Styling**: Uses Inter font family for a clean, modern look

## 🚀 Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Advanced styling with gradients, animations, and flexbox layout
- **Vanilla JavaScript**: No frameworks - pure DOM manipulation and calculations
- **Local Storage**: Persist participant data

## 🎯 How to Use

1. **Add a Participant**: 
   - Enter the person's name
   - Optionally upload a photo
   - Click "Add"

2. **Add an Expense**:
   - Enter expense description
   - Input the amount
   - Select who paid
   - Click "Add Expense"

3. **View Summary**:
   - Check real-time calculations
   - See who owes whom
   - Track spending patterns
